# Alpha Solutions Services — public org profile

This repository powers the GitHub organization profile for
[Alpha-Solutions-Services](https://github.com/Alpha-Solutions-Services).

## Update product progress

1. Edit percentages / status in [`progress.json`](./progress.json).
2. Run:

```bash
node scripts/render-progress.mjs
```

3. Commit the updated `README.md` and `assets/progress/*.svg`.

Do not invent fake metrics — keep bars aligned with real delivery maturity.
